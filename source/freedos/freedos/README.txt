FreeDOS Pocket source companion
================================

This directory preserves the official source-bearing FreeDOS package archives
selected by the package audit, plus upstream source archives for old DJGPP and
SHSUFDRV binaries whose FreeDOS 1.4 package ZIPs do not embed source files.

See manifest.json for the installed-package mapping, original media member or
upstream URL, file size, and SHA-256 of every archive. The files are retained
in their original ZIP form so their source trees, licence texts, build notes,
and timestamps are not rewritten by this packaging step.

This companion covers software inside the FreeDOS C: environment. Android app
and emulator integration source and notices are tracked separately.
